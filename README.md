# Proyecto HTML - Conquer Academia

Sitio web de una academia de programación (Clase 16 - Proyecto HTML).

Abrí `index.html` en el navegador para verlo.

## Páginas

- Home (`index.html`)
- Quiénes somos
- Cursos y detalle de cada curso
- Blog y detalle de cada noticia
- Registro
- Login
- Contacto
- Aviso legal

## Estructura

- `*.html`: páginas del sitio
- `css/estilos.css`: estilos
- `img/`: imágenes ordenadas por sección
